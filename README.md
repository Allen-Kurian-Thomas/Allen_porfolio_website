## 🛠 Tech Stack

The application relies on a modern frontend ecosystem to deliver high performance and rich aesthetics:

- **Frontend Framework:** [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite](https://vitejs.dev/) for lightning-fast HMR and optimized builds.
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) combined with custom CSS for fine-tuned aesthetics like glassmorphism and subtle gradients.
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **UI Components:** [Radix UI](https://www.radix-ui.com/) primitives & [Lucide React](https://lucide.dev/) for precise icons.
- **Deployment:** Hosted securely on [Firebase Hosting](https://firebase.google.com/docs/hosting).

> **Core Expertise:** Python, Java, HTML, CSS, JavaScript, MySQL, Laravel, Django, and React.

## � How I Developed This Site

Building this portfolio was an opportunity to showcase not just my past projects, but my approach to frontend development and design. Here is a brief look into my process:

### 1. Concept & UI Design

I started with a clear vision: a dark-themed, premium aesthetic that feels alive without being overwhelming. I focused on clean typography, subtle gradients, and glassmorphism to give a modern, polished look. I wanted the site to immediately communicate professionalism and a keen eye for detail.

### 2. Architecture & Setup

I chose **React** and **TypeScript** via **Vite** for the core architecture. This combination provided a robust, type-safe development environment with incredibly fast build times and hot module replacement. Structuring the project modularly allowed me to separate concerns efficiently—from defining data locally (`src/data/projects.ts`) to managing reusable UI components.

### 3. Styling & Animations

For styling, I heavily utilized **Tailwind CSS**. It allowed me to rapidly build out the responsive layout and custom designs without writing massive amounts of custom CSS.
To bring the site to life, I integrated **Framer Motion**. This powered the layout transitions, scroll-triggered animations, the custom interactive cursor, and the smooth infinite-scrolling tech stack marquee. The animations were carefully tuned to be fluid and non-intrusive.

### 4. Robust Integrations

I used **Radix UI** combined with **Lucide React** icons to build accessible foundation components. This allowed me to apply my own stringent design system without fighting default component styles.

### 5. Deployment & Optimization

Finally, to ensure the site relies on a robust CDN with minimal friction, I deployed it entirely through **Firebase Hosting**. The build process optimizes the React application, ensuring fast load times and a seamless user experience.
